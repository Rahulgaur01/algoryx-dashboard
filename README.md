# Algoryx Admin Dashboard - Week 1 Task

A modern, responsive, production-quality Admin Dashboard built with React, Tailwind CSS, and React Icons.

## 🚀 Features
- Responsive Sidebar & Top Navigation
- Dashboard KPI Cards with trends
- Recent Orders Table with search filter
- User Profile Card
- Notifications dropdown
- Dark Mode toggle
- Light animations & clean transitions

## 🛠️ Tech Stack
- **React (Vite)**
- **Tailwind CSS**
- **React Icons**
